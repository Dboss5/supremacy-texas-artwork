# Supremacy Service — Replaced WordPress Original Images

This dedicated GitHub branch archives original image files removed from Elementor page placements by Supremacy Bulk Image Swapper. These are **original source media files**, preserving exact bytes and extensions, not re-created or AI-generated images.

- Source site: https://supremacyservice.com
- Archive started: 2026-11-20
- Filenames: `originals/<WordPress attachment ID>-<original filename>`
- Each file's SHA-256 checksum is recorded in `archive-index.csv` for restoration verification.
- Archived files may still be in WordPress Media because other pages, media sizes, and rollback snapshots can reference them. **Do not delete originals until a usage audit confirms it is safe.**
- To restore a file, download it, upload to WordPress Media, then update the relevant Elementor references.

This branch is a historical backup, not a source gallery for new page artwork.
