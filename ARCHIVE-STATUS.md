# Original WordPress media preservation

26 original static image files have been archived in this branch, including WordPress media #4319, #4335, #14990 and #15125. Two previously attempted media transfers (#3195 and #3834) did not complete. All archived images are original bytes; SHA-256 checksums are listed in `archive-index.csv`, `archive-index-part2.csv`, `archive-index-part3.csv`, `archive-index-air-conditioning.csv`, and `archive-index-heating-hvac.csv`.

Do not delete WordPress originals before completing a shared-reference audit, confirming backups, and ensuring Elementor rollback can restore pages.

The main artwork dashboard links to `original-media-archive.html`, which lists these 26 archived originals. The historical failed transfers remain documented above and are not counted as archived files.
