How to read the usage labels +
In use · verified
The inventory records a specific page or post placement.
Imported · placement unconfirmed
A WordPress media record exists; a current placement has not been verified.
Existing · usage unverified
Established artwork whose current site usage needs reconciliation.
New · not deployed by this batch
This intake has not deployed the image. This is not a site-wide “never used” claim.

Usage is a recorded snapshot, not a live WordPress scan. Selecting or downloading an image does not change its usage status.
